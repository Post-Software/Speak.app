# speak-transcriber

Rust sidecar used by Speak for local model management and transcription.

## Commands
- `model-info --id <model_id>`
- `download --id <model_id> --dest <models_root>`
- `delete --id <model_id> --dest <models_root>`
- `worker --id <model_id> --dest <models_root>`

## Model IDs
- `voxtral_q4_fast`
- `voxtral_full_quality`
